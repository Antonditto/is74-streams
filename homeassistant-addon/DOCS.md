# is74 Streams

Веб-сервис для получения стабильных ссылок на потоки камер видеонаблюдения Интерсвязи
(`old-stream.is74.ru`) — для использования в go2rtc, Frigate и самом Home Assistant.

## Установка

1. Запустите add-on.
2. Откройте UI — либо кнопкой "is74 Streams" в боковой панели HA (Ingress), либо напрямую по
   порту `8090`.
3. **`/login`** — введите номер телефона, получите push/SMS-код в приложении Интерсвязи,
   подтвердите на **`/confirm`**.
4. **`/settings`** — выберите камеры: секция "Мои группы" покажет камеры, привязанные к вашему
   аккаунту (drill-down по папкам, кнопка "Добавить все доступные камеры"), либо введите ID
   камер вручную. Сохраните.
5. **`/streams`** — список камер с превью и ссылками (HLS, снэпшот). **`/api/streams`** — тот же
   список в JSON, для go2rtc/Frigate.

## Конфигурация

| Опция | По умолчанию | Описание |
|---|---|---|
| `internal_base_url` | *(пусто)* | Если go2rtc/Frigate работают на этом же хосте — задайте им отдельный internal-адрес для `/api/streams` (например `http://localhost:8090/`), не завязанный на Ingress-префикс. Без опции `/api/streams` отдаёт те же ссылки, что и `/streams`. |

## Токен и повторный вход

Токен авторизации живёт **год** — повторно проходить `/login` нужно примерно раз в год (или
раньше, если он был вручную сброшен через "Выйти" на `/settings`).

## Безопасность

Токен и список камер хранятся в персистентном `/data` add-on'а (входит в бэкапы HA). Ссылки,
которые сервис отдаёт наружу (в `/streams`/`/api/streams`), токена не содержат — сервис сам
проксирует обращения к CDN Интерсвязи.
