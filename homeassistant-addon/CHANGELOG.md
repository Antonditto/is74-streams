# Changelog

## 0.0.2

- Исправлен цикл редиректов / 404 при открытии веб-интерфейса через Ingress (кнопка в боковой
  панели HA) — серверные редиректы (`/`, `/login`, `/confirm`, `/settings`, `/streams`, выход)
  не учитывали Ingress-префикс.

## 0.0.1

Первый релиз.

- Вход в личный кабинет Интерсвязи (номер телефона + push/SMS-код), токен живёт год.
- Автоматический список камер аккаунта (дерево "Мои группы") + ручной ввод ID.
- Стабильные прокси-ссылки на HLS-поток и снэпшот камеры — без токена аккаунта в URL.
- `GET /api/streams` — JSON-список камер для go2rtc/Frigate.
- Поддержка Traefik/reverse-proxy и Home Assistant Ingress (кнопка в боковой панели HA).
