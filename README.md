# is74-streams

Веб-сервис, который логинится в личный кабинет Интерсвязи (`old-stream.is74.ru`) и отдаёт
стабильные ссылки на потоки дворовых камер/домофонов — для **go2rtc**, **Frigate** и
**Home Assistant**, без протухающих токенов на стороне этих приложений.

## Зачем

Интерсвязь не даёт прямого RTSP/стабильного API для камер — только веб-личный кабинет с
токеном авторизации в URL. Этот сервис — прослойка:

1. Проходит флоу входа (номер телефона + push/SMS-код) один раз — токен живёт **год**.
2. Забирает список камер, привязанных к аккаунту (свои + группы от провайдера).
3. Отдаёт go2rtc/Frigate стабильный `GET /api/streams` (JSON) с прокси-ссылками на HLS и
   снэпшоты, которые сами скрывают токен аккаунта и не меняются, пока вы не перевыберете камеры.

Подробный реверс-инжиниринг API Интерсвязи, архитектура и текущий статус — в [CLAUDE.md](CLAUDE.md).

## Возможности

- Вход по номеру телефона + код подтверждения, без ручных походов в DevTools.
- Автоматический список камер аккаунта ("Мои группы" — дерево `get-group`, plus ручной ввод ID).
- Карточки камер с превью, drag-and-drop сортировкой, копированием HLS/snapshot-ссылок.
- Светлая/тёмная/авто тема.
- Работает и как самостоятельный Docker-сервис (в том числе за Traefik/reverse-proxy), и как
  **Home Assistant add-on** — с Ingress и кнопкой в боковой панели HA.
- Отдельный "внутренний" `base_url` для `/api/streams`, если go2rtc/Frigate стоят на том же
  хосте, что и сервис (актуально для HA add-on).

## Быстрый старт (Docker Compose)

```bash
git clone git@github.com:Antonditto/is74-streams.git
cd is74-streams
docker compose up -d --build
```

Открыть `http://localhost:8090/` → войти по номеру телефона → выбрать камеры на `/settings` →
ссылки на потоки появятся на `/streams` (для человека) и `/api/streams` (JSON для go2rtc/Frigate).

Состояние (токен, список камер) хранится в `./data/state.json` на хосте — не коммитить, не
публиковать; см. [.gitignore](.gitignore) и раздел "Секреты" в [CLAUDE.md](CLAUDE.md).

## Home Assistant add-on

1. **Настройки → Дополнения → Магазин дополнений → ⋮ → Репозитории** → добавить URL этого
   репозитория (используется `repository.yaml` в корне).
2. Установить add-on **"is74 Streams"**, запустить — появится кнопка в боковой панели HA
   (Ingress), либо доступ напрямую по порту `8090`.
3. Пройти `/login` → `/settings`, как в Docker Compose-варианте. `/data` — персистентное
   хранилище Supervisor'а, входит в бэкапы HA.

Опция аддона `internal_base_url` — если go2rtc/Frigate стоят на том же хосте, задаёт им отдельный
internal-адрес для `/api/streams`, не завязанный на Ingress-префикс (см. CLAUDE.md).

## Конфигурация (переменные окружения)

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `IS74_STATE_PATH` | `/data/state.json` | Путь к файлу состояния (токен, ID камер). |
| `IS74_INTERNAL_BASE_URL` | *(не задана)* | Если задана — `/api/streams` строит ссылки на этот base_url вместо публичного (см. "Работа за Traefik / HA Ingress" в CLAUDE.md). |

## go2rtc / Frigate

Сервис не включает go2rtc — это отдельный компонент вашей инфраструктуры (свой HA add-on или
Docker-контейнер), который должен сам забирать актуальный список потоков из `GET /api/streams`.
Формат ответа — плоский JSON-список: `id`, `uuid`, `name`, `address`, `slug`, `icon`, `hls_url`,
`snapshot_url` (все ссылки уже без токена).

## Разработка

```bash
cd app
pip install -r requirements.txt
uvicorn main:app --reload --port 8090
```

Полная техническая документация — API-контракт Интерсвязи, архитектурные решения, известные
особенности окружения — в [CLAUDE.md](CLAUDE.md).

## Безопасность

- Токен живёт год и **не** передаётся третьим лицам — сервис проксирует запросы к CDN сам,
  наружу (в браузер/go2rtc) уходят только собственные ссылки без токена.
- Не коммитьте `data/` (состояние с токеном) и `*.har`-дампы — см. `.gitignore`.
- Если токен скомпрометирован — зайдите на `/login` и пройдите вход заново; старый токен
  перезапишется.
